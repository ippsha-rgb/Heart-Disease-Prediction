# Heart Disease Prediction

A machine learning web application that predicts the risk of heart disease based on patient health information.

## Project Overview

This project uses a Logistic Regression model to predict whether a person is at high or low risk of heart disease.

The trained model is deployed as an interactive Streamlit web application.

## Features

- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol
- Fasting Blood Sugar
- Resting ECG
- Maximum Heart Rate
- Exercise-Induced Angina
- Oldpeak
- ST Slope

## Machine Learning

**Algorithm:** Logistic Regression

### Libraries Used

- Python
- Pandas
- Scikit-learn
- Joblib
- Streamlit
